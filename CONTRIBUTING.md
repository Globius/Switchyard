# Contributing to Switchyard

Thanks for helping! The full guide is [docs/contributing.md](docs/contributing.md). The short version:

1. **Small fix:** open a pull request. **Bigger change:** open an issue first and say what you want to do.
2. **Set up, run the checks, write tests and docs:** the table in the guide lists the exact commands for the controller, the UI, the agent and the docs.
3. **Sign your commits** (`git commit -s`): we use the [Developer Certificate of Origin](https://developercertificate.org), no CLA.
4. **A maintainer reviews on GitHub.** When approved, your commits are forwarded unchanged to GitLab, where the project merges code, and come back
   here under your name; GitHub then shows your pull request as Merged.

Security problems: see [SECURITY.md](SECURITY.md), do not file a public issue.
