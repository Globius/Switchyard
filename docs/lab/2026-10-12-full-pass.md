## Findings

Fixed on main during the pass: !100, !103, !120, !121, !122, !124 (see the individual MRs).

Open at the end of the pass:

1. **TLS-ALPN-01** (certificate issuance thread): the first attempt fails with `HTTP 500 ... Certificate 'acme-tls-<hash>.pem'
   already exists! [new ssl cert ...]` on the first engine, in a group with three TLS services (three crt-lists). Likely the
   challenge certificate is created once per crt-list instead of once per engine, or a failed attempt leaves it behind. A failed
   attempt must also remove it.
2. **ACME TLS-ALPN-01 / HTTP-01 checks resolve names with the controller's own resolver**, so a lab needs `extra_hosts`; worth a line in
   `docs/acme.md`.
3. **Controller settings**: an IP is refused as an FQDN, so after a confirmed change there is no API path back to the default
   address (the lab cleared `controller_settings.public_url` in the database).
4. **GSLB**: `deploy/dns` needs IPv6 networking for IPv6 members (Docker `ipv6` + `ip6tables`, or host networking).
5. Lab-only: Pebble and challtestsrv are published on ghcr.io only, which has no IPv6; Pebble was built from source.
